{# Feather-style line icons, inlined as SVG. One macro per glyph rather than a single icon(name) dispatcher: a typo in `icons.wallett()` raises a Jinja UndefinedError straight away, where an {% if name == ... %} chain would silently render nothing. Every glyph inherits its container's colour via stroke="currentColor", so no icon needs its own CSS rule. All icons here are decorative and sit beside real text, hence aria-hidden — never use one on its own as the entire label of a control. #} {% macro _svg(size) -%} viewBox="0 0 24 24" width="{{ size }}" height="{{ size }}" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true" focusable="false" {%- endmacro %} {% macro edit(size=16) -%} {%- endmacro %} {% macro plus(size=16) -%} {%- endmacro %} {% macro wallet(size=20) -%} {%- endmacro %} {% macro list(size=20) -%} {%- endmacro %} {% macro heart(size=20) -%} {%- endmacro %}
